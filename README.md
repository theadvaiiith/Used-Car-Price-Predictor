# Used-Car-Price-Predictor
This project predicts the selling price of used hybrid cars using various machine learning regression algorithms. It helps users estimate accurate prices based on multiple features such as car brand, year, mileage, fuel type, and transmission type.

📘 Overview

The Hybrid Used Car Price Prediction system applies supervised machine learning techniques to analyze car data and predict its market value. The project compares multiple regression models and provides insights into which algorithm performs best for real-world price estimation.

🎯 Objectives

Predict the price of used hybrid cars accurately

Compare performance of different regression models

Visualize and analyze car features affecting prices

Build a user-friendly system for practical prediction

🧠 Machine Learning Models Used

Linear Regression

Random Forest Regressor

Gradient Boosting Regressor

Decision Tree Regressor

Each model is trained, tested, and evaluated based on performance metrics like R² score, Mean Absolute Error (MAE), and Root Mean Squared Error (RMSE).

⚙️ Workflow

Data Collection – Import dataset of used hybrid cars

Data Preprocessing – Handle missing values, outliers, and encode categorical data

Feature Selection – Choose important variables influencing car prices

Model Training – Train regression models using Scikit-learn

Evaluation – Compare model accuracy and performance metrics

Prediction – Predict selling price for new input data

💻 Tech Stack

Programming Language: Python

Libraries: Scikit-learn, Pandas, NumPy, Matplotlib, Seaborn

Tools: Jupyter Notebook / Tkinter (GUI for user input)

🧩 System Architecture

Architecture Flow:
Data Input → Preprocessing → Model Training → Prediction → Output Display

🌟 Results

The proposed system achieved higher accuracy and consistency compared to traditional pricing methods. Random Forest and Gradient Boosting performed best in terms of R² score and minimal error rates.
